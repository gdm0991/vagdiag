# Диагностика VAG — приложение для Android

Нативное приложение на Kotlin. Читает ошибки блоков управления
Volkswagen, Škoda, SEAT и Audi через адаптер ELM327.

Версия 1.2 от 21.08.2026. Разбор задачи, ради которой всё затевалось, —
в статье [«ELM327 не дочитывает ответы блоков кузова»](https://habr.com/ru/articles/1072434/).

**Зачем отдельное приложение, если есть версия для компьютера.**
Из-за Bluetooth. Профиль последовательного порта доступен только
настоящему приложению — ни из браузера, ни из Termux к нему не
подобраться. А в бардачке у большинства лежит именно Bluetooth-адаптер.

## Что умеет

| Возможность | Описание |
|---|---|
| Подключение | ELM327 по Wi-Fi, **по Bluetooth** и **по USB через кабель OTG** |
| Поиск блоков | Быстрый по известным адресам и полный перебор |
| Данные блоков | Имя, номер запчасти, количество ошибок, первый код |
| Разбор ошибок | По каждому признаку: активна, подтверждена, была ранее |
| Стирание | Очистка памяти выбранного блока |
| Двигатель OBD-II | Коды с описанием, готовность систем, VIN |
| Живые параметры | Обороты, температуры, нагрузка, напряжение |
| Монитор ошибок | Живой счётчик для поиска датчика отключением |
| Мастер поиска | Пошаговый протокол «отключил — записал» |
| Отчёт | Отправляется почтой, мессенджером или сохраняется в файл |

Про OBD-II важная оговорка. Стандартные режимы есть не у всех машин
с колодкой: в США они обязательны с 1996 года, в Европе EOBD — для
бензиновых с 2001, для дизельных с 2004. У машин с других рынков разъём
может стоять, а режимов не быть. Раньше здесь было написано «на любом
автомобиле с 2001 года» — неправда, поправлено 21.08.2026 по замечанию
kzkvv на Хабре.

## Готовый файл установки

APK лежит в [релизах](https://github.com/gdm0991/vagdiag/releases).
Android будет ругаться на установку из неизвестного источника — это
нормально для файла, который не проходил через Google Play.

Собрать самому:

1. Установить **Android Studio** (Ladybug или новее)
2. Открыть папку `android-app` через «Open»
3. Дождаться, пока среда скачает зависимости
4. **Build → Build APK(s)**

Для сборки нужен интернет: библиотека `usb-serial-for-android` живёт
на JitPack, в Maven Central её нет.

| Что | Версия |
|---|---|
| Плагин Android | 8.5.2 |
| Kotlin | 1.9.24 |
| Compose BOM | 2024.06.00 |
| Минимальная версия Android | 7.0 (уровень 24) |
| Целевая версия | 14 (уровень 34) |

## Устройство

```
MainActivity.kt        точка входа, вкладки, разрешения
DiagViewModel.kt       состояние и логика, задачи по одной за раз
core/Transport.kt      Wi-Fi, Bluetooth и USB за общим интерфейсом
core/Elm327.kt         обмен с адаптером, сборка кадров ISO-TP
core/Uds.kt            протокол блоков VAG, расшифровка, OBD-II
core/Codes.kt          словарь описаний кодов
ui/Screens.kt          экраны
```

Wi-Fi, Bluetooth и USB скрыты за общим интерфейсом `Transport`: открыть,
записать, прочитать, закрыть. Всё, что выше, не знает, по какому каналу
идёт обмен. USB добавился третьей реализацией того же интерфейса, и
логику протокола трогать не пришлось вообще.

Скорость обмена по USB подбирается перебором: 38400, 9600, 115200, 57600.
У дешёвых адаптеров она разная, и пользователь не обязан знать, что там
внутри.

### Особенности, которые дорого дались

Выяснены опытным путём на живом автомобиле. Не убирайте их, не проверив.

| Место | Почему так |
|---|---|
| Чистка буфера перед каждой командой | Иначе ответ одного блока читается как ответ следующего |
| Задачи строго по одной | Адаптер не переносит два запроса подряд |
| Снятие фильтра через `ATCF000` и `ATCM000` | `ATCRA` без параметра дешёвые адаптеры не понимают |
| Повтор при ответе «занят» | Блок остаётся занят около секунды после незавершённой передачи |
| Пауза 1,5 секунды между выборками ошибок | По той же причине |
| Заявленная длина берётся из заголовка | Позволяет знать число ошибок, даже когда список не дочитан |
| Расширенная сессия перед стиранием | Без неё блок отвечает отказом |
| Самовосстановление при череде пустых ответов | Дешёвые адаптеры замолкают после десятков команд |

## Длинные ответы блоков кузова

Прошивка ELM327 ведёт многокадровый обмен ISO-TP с парой адресов
двигателя. Блок кузова отвечает с другим смещением, кадра разрешения
на продолжение туда не уходит, и список ошибок обрывается на первом
кадре.

С версии 1.2 приложение не сдаётся сразу, а перебирает три способа —
ту же лестницу, что давно была в версии для компьютера:

```
1. ATCRA<адрес>                        адаптер ведёт обмен сам
2. ATCRA + ATFCSH/ATFCSD/ATFCSM1       кадр разрешения задан вручную
3. ATCAF0, сырые кадры                 разрешение шлёт сама программа
```

Сработавший способ запоминается и пишется в журнал:

```
0x70A: длинный ответ дочитан — адаптер справился сам (ATCRA)
```

**Границы этого утверждения.** На моём клоне, представляющемся как v1.5,
не срабатывает ни один из трёх — лестница доходит до конца и приложение
берёт число ошибок из заголовка первого кадра. На адаптерах, где `ATCRA`
работает, список читается целиком. Проверено пока только через
программную заглушку адаптера. Если у вас сработала первая или вторая
ступень — напишите в issue, какая плата и что адаптер отвечает на `ATI`.
Из таких строчек собирается список «какой адаптер что умеет», которого
нигде нет.

**Не поддерживается TP 2.0** — автомобили VAG примерно до 2010 года.

## Чем эта версия отличается от компьютерной

Это самостоятельное приложение, а не обёртка: протокол переписан на Kotlin.

В передаточном файле версии 1.0 было написано «переписана один в один».
Это оказалось неправдой: лестница из трёх способов в порт не попала,
и до версии 1.2 приложение получало первый кадр и останавливалось.
Нашлось это только сверкой кода с кодом, после комментария 200sx_Pilot
на Хабре. Заглушка разницы не показывала — она в обоих случаях отдавала
только первый кадр.

Что осталось только на компьютере: адаптеры USB-CAN по протоколу SLCAN,
сравнение снимков «до и после», тест аккумулятора, сохранение отчётов
в файлы рядом с программой.

Что есть только здесь: Bluetooth-адаптеры.

## Предупреждение

Приложение работает с электроникой автомобиля. Всё, кроме явного
стирания ошибок, выполняется только на чтение, но ответственности
за последствия автор не несёт.

Не пользуйтесь во время движения. Диагностика выполняется на стоящем
автомобиле с включённым зажиганием и заглушенным двигателем.

Стирание ошибок удаляет историю неисправностей, а для двигателя ещё
и сбрасывает готовность систем самодиагностики — после этого потребуется
несколько десятков километров пробега, иначе техосмотр не пройти.
