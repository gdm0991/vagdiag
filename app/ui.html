Адаптер

Адаптер вставлен в разъём OBD, зажигание включено, двигатель заглушен, компьютер подключён к сети Wi-Fi адаптера. Адрес по умолчанию подходит большинству адаптеров; свой смотрите в свойствах подключения Wi-Fi как «шлюз по умолчанию».
USB и Bluetooth адаптеры видны в системе как COM-порт. Для Bluetooth сначала выполните сопряжение в настройках Windows — после этого появится исходящий порт, его и выбирайте.
Снимает главное ограничение. Прошивка ELM327 дочитывает длинные ответы только у двигателя, поэтому списки ошибок блоков кузова видны не целиком. USB-CAN отдаёт сырые кадры шины, а сборку программа делает сама — списки читаются полностью. Подходят CANable, CANtact и совместимые. Для комфортной шины VAG выбирайте 500 кбит/с.

Поиск блоков

Быстрый поиск проверяет известные адреса блоков VAG и занимает полминуты. Полный перебирает все 256 адресов — дольше, но найдёт нестандартные блоки. Затем «Собрать данные» опрашивает каждый найденный блок: имя, номер запчасти и количество ошибок.

Монитор активных ошибок

Поиск неисправного датчика отключением.
  1. Зажигание включено, двигатель заглушен, задняя передача включена — без неё блок датчики не опрашивает
  2. Отключить все датчики бампера, запустить монитор, запомнить число
  3. Подключать по одному, после каждого ждать 10–15 секунд
  4. Счётчик уменьшился — канал исправен. Не сдвинулся — вот дефект

Мастер поиска неисправного датчика

Как построить карту «датчик — код».
  1. Зажигание включено, двигатель заглушен, задняя передача включена
  2. Все датчики подключены. Подписать шаг «исходное» и снять показание
  3. Отключить один датчик, подождать 15 секунд, подписать его название и снять показание
  4. Подключить обратно, перейти к следующему
В столбце «Код» будет виден номер ошибки, появившейся при отключении именно этого датчика. После обхода всех датчиков получится готовая карта соответствия — и станет понятно, какому датчику принадлежат коды, висящие в памяти постоянно.

Порядок работы

  1. Вставить адаптер в разъём OBD, включить зажигание, двигатель не запускать
  2. Подключиться к сети Wi-Fi адаптера, затем нажать «Подключиться»
  3. Вкладка «Блоки» → «Быстрый поиск» → «Собрать данные по всем»
  4. Кнопка «Ошибки» напротив нужного блока — подробный разбор
  5. Кнопка «Стереть» — очистка памяти ошибок этого блока
  6. Вкладка «Монитор» — поиск неисправного датчика отключением
  7. «Сохранить отчёт» — один файл со всеми данными и полным обменом

Ограничения

Программа работает по протоколу UDS. Дешёвые адаптеры ELM327 не умеют дочитывать длинные ответы от блоков кузовной электроники, поэтому по каждой выборке виден только первый код. Количество ошибок при этом определяется точно. Для чтения полных списков нужен интерфейс, отдающий сырые кадры CAN.
